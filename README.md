# tableau-hr-analytics
Interactive Tableau dashboard analyzing employee demographics, workforce trends, and HR performance metrics
👥 HR Analytics Dashboard | Tableau

📌 Project Overview

This project uses Tableau to analyze workforce data and present HR-related metrics through an interactive dashboard. It aims to help users understand employee demographics, workforce distribution, and key HR trends.

🎯 Project Objectives

- Analyze employee demographics and workforce composition.
- Examine workforce distribution across departments.
- Explore employee performance and other HR metrics where available.
- Identify workforce trends and patterns.
- Support data-driven HR decision-making.

🛠️ Tools & Technologies

- Tableau — Dashboard development and data visualization.
- Microsoft Excel / CSV — Data preparation and storage, where applicable.
