# tableau-hr-analytics
Interactive Tableau dashboard analyzing employee demographics, workforce trends, and HR performance metrics
👥 HR Analytics Dashboard | Tableau

Project Overview

This project focuses on analyzing human resources data using Tableau to understand workforce composition, employee demographics, and organizational trends. The dashboard presents HR data through visualizations to help explore workforce metrics and support data-driven HR decision-making.

Project Objectives

- Analyze employee demographics and workforce composition.
- Evaluate employee distribution across departments.
- Explore workforce trends and patterns.
- Analyze employee attrition and retention, where applicable.
- Support informed human resource management decisions.

Tools & Technologies

- Tableau
- Microsoft Excel
- Data Visualization
- Business Analytics

Analysis & Methodology

- Explored HR data to understand workforce characteristics.
- Analyzed employee-related metrics and demographic patterns.
- Evaluated workforce distribution across relevant categories.
- Developed visualizations to communicate HR trends.
- Created an interactive Tableau dashboard for workforce analysis.

Key Features

- Employee demographics analysis.
- Department-wise workforce analysis.
- Workforce distribution and trend analysis.
- Employee attrition analysis, where supported by the data.
- Interactive visualizations for exploring HR metrics.

Business Value

The dashboard helps users understand workforce composition, explore employee trends, and evaluate relevant HR metrics. These insights can support workforce planning, employee retention strategies, and informed human resource management decisions.
